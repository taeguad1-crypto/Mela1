# OWNER · REVERSE12 Global Product Guide

Static multilingual product presentation site for global partners.

- Simplified Chinese by default with Chinese, Japanese, English and Korean switching
- Browser speech synthesis and voice navigation in all four languages
- Responsive mobile layout and image lightbox
- Deduplicated product, technology, and clinical visuals with localized image guides
- Direct contact panel without subscription or trial screens

Open `dist/index.html` locally or publish the `dist` directory with GitHub Pages.
