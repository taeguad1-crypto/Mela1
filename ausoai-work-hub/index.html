무료 체험 · 사용량

기본 번역·음성·편집·메일 기능은 무료 사용량 범위에서 체험하고, 한도 도달 시 플랜 안내를 제공합니다.

계정 · 로그인

개인 작업공간·메일·관리자 기능은 로그인 후 사용하며, 계정별 데이터와 프로젝트를 분리합니다.

개인정보 · 보안

비밀번호 직접 저장을 피하고 OAuth·최소권한·세션 관리·접속기록·연결해제 정책을 우선 적용합니다.

프로젝트 · 버전

작업 원본·수정본·최종본·배포본을 구분하고, 작업 이력과 복구가 가능하도록 관리합니다.

번역 · 글로벌

선택 언어를 세션 동안 유지하고, 페이지 이동 후에도 같은 언어 설정을 이어가는 것을 목표로 합니다.

음성 · 실행

음성·문자·터치가 같은 명령 체계를 사용하며, 이동형 마이크 HUD에서 질문과 실행을 이어갑니다.

메일 · 외부연동

Gmail·Naver·Outlook 등은 공식 로그인과 권한 동의를 기준으로 연결하며, 계정별로 분리합니다.

기업 · 관리자

기업용은 관리자·직원·팀 권한을 분리하고, 감사로그·조직별 작업공간·기업 정책을 적용합니다.

업로드 · 다운로드 보안

파일 유형·용량·출처·검사 상태·다운로드 이력을 기록하고 공유 만료와 외부 반출 정책을 연결합니다.

국가별 Compliance

국가·언어·서비스 기능에 따라 개인정보·쿠키·AI 고지·전자상거래·국외이전 정책 버전을 분리합니다.

배포 전 Release Gate

API 키 노출·관리자 화면·약관 연결·보안 설정·외부자산 권리를 점검한 뒤 배포하도록 설계합니다.

감사 · 증빙 · 복구
